# 复现证据选择

此 reference 是证据选择梯，不是必须逐层执行的 pipeline。优先最接近真实症状且能回答当前假设的证据形态。

## 证据形态

### 原始 artifact
消费用户提供的原始材料：入口点、error 文本、日志片段、截图中的文本信息。

### 直接入口观察
从原始 artifact 提取可重复的入口点，在目标环境中直接触发并观察。记录实际行为与期望行为的差异。

### 运行时捕获
在目标环境中记录足以回答当前假设的输入语义、输出行为和运行时 evidence pointer。内容必须脱敏，不复制与判断无关的原始 source 数据。

### 最小构造 repro
将触发条件压缩到最小可重复形式：最小数据集、最小配置、最小操作序列。

附件通过 START 阶段确认的 source route 获取。

## 等价性验证

构造 repro 与原始 artifact 比对时，覆盖所有在当前产品/source 中实际存在且会改变 root-cause 判断的维度，例如：
- 原始输入语义与运行时实际解释
- 可稳定识别当前症状的 failure signature
- 症状发生的实际执行边界
- 当前 claim 依赖的 identity、配置、数据或依赖前提

所有适用的关键维度都能解释原始症状时，构造 repro 才足以支持 patch。无法证明等价时，构造 repro 只是假设生成器，不能支持 patch 或 verified claim。

## 多层转义

涉及多层转义的内容，分别记录原始字符串和各层解析值。不把展示格式、代码字符串和运行时值混为一个结论。

## 选择验证方式

选择最接近原始症状、最能区分当前假设、且在授权范围内可执行的证据路径。切换路径时记录原路径为何不足，以及新路径要验证的具体关系。
