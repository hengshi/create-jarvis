# 需要删除或改写的表达

## 铺垫式开头

删除宣布、预热或制造悬念的句子，直接陈述内容：

- “先说结论”
- “事情是这样的”
- “真正的问题是”
- “值得注意的是”
- “接下来我们将”
- “不妨让我们”
- “必须强调的是”

## 无意义强调

删除不增加事实的信息：

- “非常”“极其”“真正”“本质上”“显然”
- “毫无疑问”“毋庸置疑”
- “这一点非常重要”
- “请记住”“让我们拭目以待”

## 空泛商业词

用具体动作和对象替换：

| 避免 | 改写方向 |
|---|---|
| 赋能 | 谁获得了什么能力 |
| 闭环赋能 | 哪个步骤完成了验证和交付 |
| 深度融合 | 哪两个系统以什么接口协作 |
| 全方位提升 | 哪个指标从什么状态变成什么状态 |
| 打造抓手 | 谁执行什么动作 |
| 方法论沉淀 | 具体写入哪个 skill、工具或测试 |

## 元叙述

删除作者对文章结构的旁白：

- “下面详细展开”
- “前文已经提到”
- “在这一部分”
- “让我们回到主题”
- “以上就是全部内容”

读者应当通过标题和内容理解结构，不需要作者反复说明。
